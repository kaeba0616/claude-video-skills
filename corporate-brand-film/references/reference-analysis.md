# 2. 시나리오 설계 공식

## 2-1. 5막 구조 — 28편 중 22편이 이 뼈대를 그대로 쓴다

```
[0] 콜드오픈      0~35초   나레이션 없음. 음악 + 비주얼 몽타주 + 타이틀
[1] 정의 / 선언   20~40초  "우리는 ○○하는 기업입니다" 또는 본질 재정의
[2] 근거 / 역사   40~90초  창업연도 + 숫자 + 최초/최대 실적
[3] 전환          5~15초   ★"하지만 우리는 여기서 멈추지 않았습니다"
[4] 미래 / 사업부 60~240초 챕터별 상세 (2~5개 블록)
[5] 클로징        15~30초  슬로건 → 사명 → 로고 (2단)
```

콜드오픈 길이는 편마다 다르다: 유한킴벌리 2초 / 현대모비스 5초 / 현대트랜시스 10초 / 대우조선해양 13초 / 삼양목장 24초 / 롯데알미늄 28초 / **현대위아 34초**. 길수록 "브랜드필름", 짧을수록 "설명영상".

## 2-3. ★가장 중요한 장치: "하지만" 전환

거의 모든 편의 중간 지점(전체 길이의 35~50%)에 **자기 부정 → 재도약** 문장이 박혀 있다. 이게 영상에 2막을 만들어준다.

- "**하지만** 우리는 거기서 멈추지 않았습니다." (현대위아 1:12)
- "**하지만** 우리는 여기에 만족하지 않았습니다." (현대위아 2:51)
- "우리의 항해는 **여기서 끝나지 않습니다**." (대우조선해양 3:39)
- "**하지만** 우리가 반드시 넘어서야 할 문제들은 새롭게 모습을 드러냈습니다." (현대트랜시스 0:39)
- "**하지만** 우리는 거기서 멈추지 않았습니다" 직후 **곧바로 자문형 질문**이 온다 →

## 2-4. 자문형 질문 = 챕터 전환 신호

- "아주 작은 낭비조차 없도록 **공장이 스스로 생각하고 판단할 수는 없을까?**" (현대위아)
- "**기업이 사람과 환경을 위해 무엇을 할 수 있을까?**" (유한킴벌리)
- "**완벽할 수는 없을까?**" (정관장)

- "그런데 **기술과 인프라가 이렇게 발전하면 어떻게 될까요?**" (쏘카)

질문 → 답(우리 기술) 구조. 자랑을 문제해결로 위장하는 장치다.

# 3. 나레이션 문법

## 3-1. 발화 속도 = 포맷 판별기

| 유형 | 속도 | 해당 편 |
|---|---|---|
| 감성 성우 (느리게, 여백) | **2.7~3.0 자/초** | 삼양목장, 삼양식품, 파크로쉬, 현대트랜시스 종합 |
| 표준 기업 나레이션 | **3.5~4.7 자/초** | 대우조선해양, 정관장, 현대모비스, 롯데알미늄, 세아CSS |
| 설명형 / 정보 밀도 높음 | **4.8~5.4 자/초** | ADT캡스, 국립아시아문화전당, 유한킴벌리 |
| 인터뷰 실제 발화 | **5.4~5.9 자/초** | 네이버 1784, 각 세종, 쏘카 |

> **대본 분량 계산법: 60초 영상 = 순수 발화 45초 × 4자/초 ≒ 180자.** 여기에 콜드오픈·여백 20~25%를 뺀다.

## 3-2. 문장 길이

평균 24~95자. 감성편일수록 길고(파크로쉬 77자, 현대트랜시스 95자), 설명편일수록 짧다(유한킴벌리 CSV 24자, 삼양목장 30자).

## 3-3. 반복(anaphora)으로 리듬 만들기

- "**매일** 새로운 태양이 떠오르고, **매일** 새로운 바다가 차오르듯, **매일** 새로운 도전이 시작되는 곳." (대우조선해양)
- "**더** 정확하게. **더** 선명하게. 그래서 가장 안전하게." (ADT캡스)
- "**더** 안전하고 **더** 편리하고 **더** 친환경적인" (현대모비스)
- "정직한 마음, 환경을 생각하는 배려, 고객에 대한 진심, 기술에 대한 사명 / **우리는, 우리는, 우리는** 세아창원특수강입니다" (세아CSS)
- "숲은 푸른데 생활은 푸르지 않고, 숲은 많은데 생활과 가깝지 않죠." (유한킴벌리)

## 3-4. 상투구 사전 (그대로 쓰면 이 톤이 난다)

`이전에 없던` `~의 중심에 우리가 있죠` `세상은 새로운 기술을 요구합니다` `우리는 멈추지 않습니다`
`한 치의 오류도 허용하지 않는` `단 하나의 오류도 허용하지 않는다` `~을 아우르는` `~을 선도합니다`
`지속가능한 미래를 위해` `언제나 당신과 함께하겠습니다` `그 위대한 역사는 계속됩니다`
`~라는 사명감으로` `~에 안주하지 않고` `세계 최초·국내 최초·세계 최대`

## 3-5. 주어 전략

거의 전편이 **"우리"** 1인칭 복수. 사명(社名)은 도입부 1회, 클로징 1~2회만. 중간엔 "우리"로 밀어 감정이입을 만든다. 반대로 정관장 국내편·유한킴벌리 CSR은 **"당신"** 2인칭을 섞어 관계형 톤을 만든다.

## 4-1. 컷 리듬 = 콘텐츠 유형의 직접 함수

```
27~33컷/분 ─ 하이라이트·제품 카탈로그 (세아CSS, 현대위아, 대우조선해양)
39컷/분   ─ 쇼릴
```

**섹션 내부 가속**이 핵심 테크닉이다. 현대위아를 보면:

```
0:00-0:34 콜드오픈    6컷 / 34초 = 5.7s/컷   ← 느리게 시작
0:34-1:08 1챕터      19컷 / 34초 = 1.8s/컷   ← 확 당김
2:09-2:40 2챕터      19컷 / 31초 = 1.6s/컷
2:51-4:22 3챕터+클라이맥스 56컷 / 91초 = 1.6s/컷
4:27      로고        1컷                    ← 정지
```

즉 **느리게 열고 → 조이고 → 멈춘다.** 28편 공통.

## 4-2. 샷 사이즈 배치 (컨택시트 관찰)

거의 모든 편이 이 5종을 로테이션한다:

1. **드론 익스트림 와이드** — 공장 전경, 캠퍼스, 바다 (섹션 오프닝용)
2. **극단적 클로즈업** — 손, 부품, 소재, 액체, 스파크 (전환·리듬용)
3. **인물 미디엄 (일하는 모습)** — 연구원, 작업자, 관제실 (신뢰용)
4. **CG / 3D 다이어그램** — 제품 분해, 데이터 흐름, 지도 (설명용)
5. **화이트 스튜디오 제품샷** — 무배경 흰색 위 제품 (카탈로그용)

세아CSS·롯데알미늄이 특히 전형적: 실사 공장샷 ↔ 화이트 스튜디오 제품샷을 번갈아 친다.

## 4-3. 온스크린 타이포 3계층

컨택시트에서 반복 확인되는 자막 시스템:

| 계층 | 위치 | 형식 | 예시 |
|---|---|---|---|
| **챕터 타이틀** | 화면 중앙 / 좌상단 | 대문자 영문 볼드, 컬러 배경 | `NEXT MOVE`, `Tech Platform`, `TRUST AND PASSION` |
| **기술 라벨** | 좌하단 또는 우하단 | 한글 굵게 + 영문 부제 (챕터 타이틀과 달리 전부 대문자로 쓰지 않는다) | `자율주행 시스템 / Autonomous Driving & ADAS`<br>`무계목 강관 / STS Seamless Pipe & Tube`<br>`실시간 모니터링 서비스 / HW-MMS PT` |
| **나레이션 자막** | 하단 중앙, 작게 | 얇은 흰 글씨 | 대사 그대로 |

**규칙: 기술 라벨은 반드시 한글+영문 2단.** 이게 "기업홍보영상 룩"의 8할이다.

## 4-4. 컬러 그레이딩

- 제조·중공업 (세아CSS, 대우조선해양): **오렌지 용광로 ↔ 시안 금속** 강한 보색 대비
- IT·모빌리티 (네이버, 현대모비스, 현대케피코): **저채도 블루-그레이**, 하이라이트 클리핑
- 식품·헬스 (정관장, 삼양식품, 유한킴벌리): **웜 앰버 + 자연광**
- 공간·감성 (파크로쉬, 삼양목장, ACC): **디새추레이티드, 안개, 롱렌즈**

# 5. 모듈러 제작 전략 (이게 실무의 핵심)

시네마틱퍼슨은 **한 번 촬영해서 여러 편을 뽑는다.** 플레이리스트 자체가 증거다.

```
현대트랜시스   07 종합(2:01) ─┬─ 08 자율주행 인테리어 편(3:08)
                              └─ 09 전동화 파워트레인 편(3:00)
유한킴벌리     12 종합(1:27) ─┬─ 13 Innovation(1:54)
                              ├─ 14 CSR 우리강산(1:40)
                              └─ 15 CSV 액티브시니어(1:59)
정관장         11 국내 고객용(3:38) ↔ 10 글로벌 고객용(5:17)   ※ 같은 소재, 다른 톤
삼양식품       17 기업(4:46)  ↔ 18 삼양목장(3:04)
삼성디스플레이  03 Highlight(1:29) = 본편의 압축본
```

**설계 순서:**
1. 풀렝스 마스터(4~7분)를 챕터 단위로 설계
2. 각 챕터를 단독 상영 가능하게 자기완결(자체 오프닝·클로징 보유)
3. 챕터의 첫 문장·마지막 컷만 뽑아 1~1.5분 **종합편** 조립
4. 나레이션 걷어내고 음악만 얹어 60~90초 **하이라이트**

현대모비스(06)는 이걸 한 편 안에 넣은 케이스다:
```
0:00-1:17 프롤로그(=종합편 그 자체) → 1:17-1:47 무나레이션 챕터 브릿지
1:47-2:23 자율주행 → 2:27-3:09 인포테인먼트 → 3:14-3:53 전동화 → 3:53-4:33 에필로그
```

# 6. 사운드 설계

- **음악이 구조를 만든다.** 콜드오픈=앰비언트 패드 → 1막=리듬 진입 → 전환부=브레이크(악기 빠짐) → 클라이맥스=풀 오케스트라/브라스 → 로고=단음 스팅어.
- 네이버 1784는 크레딧에 **음악: 윤석철**을 명시 — 오리지널 스코어. 나머지는 라이선스 트랙 추정.
- 무나레이션 구간(전체의 8~46%)은 버리는 시간이 아니라 **음악이 감정을 올리는 구간**이다. 삼양목장은 32%, ACC는 46%가 무나레이션.
- 인터뷰형(01, 02, 15, 21, 27)은 나레이션 없이 **사운드바이트만으로 논리를 이어붙인다.** 질문은 화면에 안 나오고 답변만 편집으로 연결.
